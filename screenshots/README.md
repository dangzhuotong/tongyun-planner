## 中英文介绍截图

README 中文版使用本目录的 `dashboard.png`、`matrix-view.png`、`sticky-notes.png`、`calendar-view.png` 和 `analytics.png`。英文版使用 `en/` 下的同名图片；两版首图均为首页。

这两组图片来自当前开发版实际界面，使用隔离浏览器来源中的演示任务、日记、便签和专注记录，不含个人真实数据。切换应用语言后分别截图，未在图片上替换文字。
