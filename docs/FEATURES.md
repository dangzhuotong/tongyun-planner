# 橦云手帐 · 功能详单

产品定位与下载见 [README](../README.md)。下面是当前版本里已经有的能力，方便对照界面，而不是 README 首页的营销清单。

**In English:** an offline-first, privacy-first desktop bullet journal — Eisenhower matrix task manager, flip-page diary, pomodoro timer with white noise, sticky notes and a floating desktop widget, all in one local-first desktop app. Open source (MIT), no account, no server collecting your notes; optional multi-device sync through your own WebDAV.

## 任务

基于艾森豪威尔矩阵（重要 / 紧急）：

| 象限 | 分类 | 策略 |
|:---:|:---|:---|
| **I** | 重要且紧急 | 立即处理 |
| **II** | 重要不紧急 | 计划安排 |
| **III** | 紧急不重要 | 委托或缩短 |
| **IV** | 不重要不紧急 | 尽量不做 |

- 矩阵 / 列表 / 日历 / 甘特图
- 子任务、标签、截止日期、收藏、已完成归档
- 开发分支支持项目归类、按项目和到期日期筛选，以及保存常用筛选组合。
- 单任务可设多个提醒时间，应用运行期间可在手帐内完成任务或延后 10 分钟提醒。
- 命令面板（Ctrl/Cmd+K）全文搜索任务与日记
- 今日到期桌面通知（有时刻则按时刻；无时刻默认上午 9:00）

## 翻页日记

- 按日翻页、顶部日期滑条、农历与心情
- 纯文字书写（导出仍为 Markdown）
- `#标签` 筛选、单篇 / 整本导出
- 图片附件在桌面端存为本地文件。完整 ZIP 备份可一起搬迁附件；普通 JSON 快照和 WebDAV 同步仍不自动复制附件文件。
- 可选：日记自动生成当日待办（删除后不会再被同步 effect 复活）

## 习惯与专注

- 习惯打卡嵌在主页与日记关联区（不单开页面）
- 番茄钟、白噪音（程序化生成，无音频文件）
- 26 周专注热力图、本周速览
- 心流模式：一次只看一项任务

## 资讯与便签

- 热榜 / RSS / GitHub / 视野 / 稍后读
- 资讯一键：稍后读、存为任务、收藏到日记
- 彩色便签、桌面浮动窗、小组件（卡片 / 列表 / 番茄 / 便签）

## AI（可选）

需在设置里填写你自己的模型服务。OpenCode / Ollama 可以不填 Key。

- 智能收件箱、自动归类、任务拆解、标题润色
- 日记暖评、每日建议、治愈散文、周报、资讯摘要

## 数据存储

- 桌面端默认使用本机 SQLite，无需外部数据库或 DSN；任务、日记等使用独立领域表。
- 兼容实现仍保留 localStorage 与 SQLite `storage` 表，部分本地配置以 JSON 保存；浏览器开发环境及 SQLite 不可用时使用 localStorage 降级。
- WebDAV 是可选的跨设备同步通道，由同步引擎按分类整包读写；同步范围为任务、已完成任务、便签、番茄记录、倒数日、日记和应用配置。
- 记账条目包含在本地快照中；习惯、资讯收藏等不在当前 WebDAV 分类中。
- AI Key 默认不同步，快照不含密钥；主动开启「同步 API 密钥」并设置口令后，可加密上传至自己的 WebDAV。本机配置存储不等同于系统钥匙串。
- 兼容表中保留的 Agent 数据不表示开源版提供派活功能。旧 Supabase / 自建 HTTP 同步已停用。
- 开发分支提供[本机 Agent API / MCP](AGENT_API.md)，支持查询与创建任务、便签、日记；默认关闭，设置页支持分权授权、撤销和查看近期操作。创建支持幂等键。

## 日历与日记

- 日历支持从待办安排时间，也可以拖入 30 分钟或 60 分钟区。时间盒可编辑，选中日期的时间盒与待办可导出为 `.ics` 文件。
- 日历支持导入外部 `.ics` 文件或订阅 HTTPS iCalendar 链接，显示当天会议并提示与时间盒重叠。
- 日历按天展示计划时长和实际专注时长，可将复盘追加到当日日记。
- 日记编辑器可以插入晨间页面、每日复盘、周回顾和自由记录模板。插入模板时保留已有正文。

## 同步与备份

- WebDAV 同步（内置坚果云预设，需使用坚果云「应用密码」；也支持自定义 WebDAV 地址）
- 启动、关闭、每 5 分钟自动同步，编辑停止约 30 秒后上传；离线可用，待上传分类保存在本机，联网后补传
- 冲突检测：云端被其他设备改动时先把两端副本存到 `backups/conflicts/`，再由你选择保留哪份，不静默覆盖
- 每日本地自动快照（保留最近 14 份）；快照导入 / 导出 JSON（不含密钥）
- 手动完整 ZIP 备份包含任务、日记及其附件、便签、番茄记录、倒数日、时间盒、习惯、记账与保存的筛选。恢复先预览，合并时保留现有同 ID 记录和同日日记。
- 支持常见 Todoist / 滴答待办 CSV 的预览导入。重复导入同一文件时跳过已存在记录。
- v1.1 起应用内自动更新（v1.0 需手动安装一次）
- 多窗口（主窗口 / 挂件 / 浮动便签）状态同步

## 外观

主题色、卡片纹理、字体、玻璃质感、深色模式、日落暖色。界面默认中文，设置可切 English。
