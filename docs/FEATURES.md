# 橦云手帐 · 功能详单

产品定位与下载见 [README](../README.md)。下面是当前版本里已经有的能力，方便对照界面，而不是 README 首页的营销清单。

## 任务

基于艾森豪威尔矩阵（重要 / 紧急）：

| 象限 | 分类 | 策略 |
|:---:|:---|:---|
| **I** | 重要且紧急 | 立即处理 |
| **II** | 重要不紧急 | 计划安排 |
| **III** | 紧急不重要 | 委托或缩短 |
| **IV** | 不重要不紧急 | 尽量不做 |

- 矩阵 / 列表 / 日历 / 甘特图
- 子任务、标签、截止日期、收藏、已完成归档
- 命令面板（Ctrl/Cmd+K）全文搜索任务与日记
- 今日到期桌面通知（有时刻则按时刻；无时刻默认上午 9:00）

## 翻页日记

- 按日翻页、顶部日期滑条、农历与心情
- 纯文字书写（导出仍为 Markdown）
- `#标签` 筛选、单篇 / 整本导出
- 图片附件在桌面端存为本地文件，不进 JSON
- 可选：日记自动生成当日待办（删除后不会再被同步 effect 复活）

## 习惯与专注

- 习惯打卡嵌在主页与日记关联区（不单开页面）
- 番茄钟、白噪音（程序化生成，无音频文件）
- 26 周专注热力图、本周速览
- 心流模式：一次只看一项任务

## 资讯与便签

- 热榜 / RSS / GitHub / 视野 / 稍后读
- 资讯一键：稍后读、存为任务、收藏到日记
- 彩色便签、桌面浮动窗、小组件（卡片 / 列表 / 番茄 / 便签）

## AI（可选）

需在设置里填写你自己的模型服务。OpenCode / Ollama 可以不填 Key。

- 智能收件箱、自动归类、任务拆解、标题润色
- 日记暖评、每日建议、治愈散文、周报、资讯摘要

## 同步与备份

- WebDAV（坚果云等）、自建 HTTP sync-server、Supabase
- 快照导入 / 导出 JSON
- 多窗口（主窗口 / 挂件 / 浮动便签）状态同步

## 外观

主题色、卡片纹理、字体、玻璃质感、深色模式、日落暖色。界面默认中文，设置可切 English。
