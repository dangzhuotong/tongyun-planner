# 橦云手帐 11 月 12 日验收

验收版是独立的 macOS 应用，窗口标题带「验收」。在 tongyun-dev 选择「橦云手帐验收包」即可启动，运行中可以直接切到该窗口。验收版使用独立的 SQLite 与 WebView 数据目录，里面的任务、便签、日记和授权都是验收数据。Agent 接口地址为 `http://127.0.0.1:17321/v1/agent`。

| 阶段 | 手工验收步骤 | 预期结果 |
| :--- | :--- | :--- |
| P0 任务可靠性 | 新建待办，在主窗或挂件删除它，关闭并重开验收版。再新建一条，删除后点撤销。 | 重开后已删任务保持删除，撤销后第二条任务恢复。清空任务后再重开，示例任务不会再次出现。 |
| P1 Agent | 打开「设置 → Agent」，为一个测试客户端只勾选「查询任务」。用该令牌连接 MCP，刷新操作记录，再撤销授权。 | 工具列表只有查询任务。操作记录出现客户端名、操作和结果。撤销后原令牌不可用。 |
| P1 重复创建 | 对有创建权限的客户端，用同一个 `requestKey` 和相同标题调用两次 `create_task`，再换标题复用该键。 | 两次相同调用返回同一个记录 ID。修改参数复用同一个键会被拒绝。 |
| P2 时间盒与日历 | 在「待办清单 → 日历日程」新增本日待办，点「排时间」，或拖入 30/60 分钟区。保存后调整时间，点「导出 .ics」。 | 时间盒显示正确起止时间，结束早于开始时禁止保存。导出的日历文件可在外部日历中导入。 |
| P2 日记模板 | 在「日记手账」写一段正文，再选择「每日复盘」或其他模板。 | 模板追加到正文末尾，原有文字保留。 |

已执行的自动检查包括 747 项前端测试、42 项 Rust 测试、生产前端构建与 macOS 验收包构建。已在实际 macOS 验收包验证六项 MCP 操作，也通过原生界面核对了授权和审计。重启后的记录与幂等回执均已读回。浏览器双窗口验证删除后重开不复活，浏览器日历验证 60 分钟拖放、编辑、下载及日记模板追加。同日覆盖和同键改参数均被拒绝。双 WebDAV 客户端用同一个隔离 HTTP 服务验证了清空传播、离线编辑保留及冲突。实际外部 WebDAV 服务和两个物理设备仍待验收。

外部日历联动目前通过按日导出 `.ics`。账户级双向同步尚未实现。Agent 的配置和调用格式见 [Agent 接入说明](AGENT_API.md)。


## 主流桌面功能

| 入口 | 验收步骤 | 预期结果 |
| :--- | :--- | :--- |
| 待办清单 → 日历日程 → 外部日历 | 选择 `.ics` 文件，或连接有权限访问的 HTTPS 订阅地址。给同一天的待办安排一段重叠的时间。 | 日程出现在当天侧栏，时间盒标出重叠。已有时间盒可以继续用 `.ics` 导出。 |
| 设置 → 备份同步 → 完整备份与迁移 | 导出 ZIP，再打开一个含图片的备份样例。检查预览后确认。 | 新增日记与附件；已有同 ID 记录、同日日记保留。 |
| 设置 → 备份同步 → 选择待办 CSV | 预览并导入 Todoist 或滴答导出的待办 CSV。再次导入同一份。 | 有效任务进入手帐，重复 ID 跳过。日期支持 ISO 日期，无法识别的日期保留为空。 |
| 待办列表 / 任务详情 | 给一条任务填写项目，在待办列表组合项目、日期和标签筛选，再给组合命名。 | 可以从保存的筛选中重新打开这套条件。 |
| 任务详情 → 任务提醒 | 设为自定义，选择到期和提前时间，保持桌面版运行。 | 到提醒时间出现手帐内提示，可以完成、关闭或延后 10 分钟。系统通知取决于系统权限。 |
| 日历日程 → 写入当日日记 | 安排时间盒，再对比当天番茄专注分钟数并点击写入。 | 原有正文保留，新增计划时间、实际专注和待办完成情况。 |

macOS 验收包已实测含 PNG 的 ZIP 恢复与重新导出、CSV 导入后读回项目、外部 `.ics` 文件显示和重叠提示，以及复盘写入当日日记。测试通过 754 项前端用例、42 项 Rust 用例和 macOS 打包。HTTPS 日历订阅尚未连接真实个人账户，手机端和外部日历账号写回暂缓。

本机备份、恢复、筛选和复盘无需云存储。HTTPS 日历订阅读取用户已拥有的日历服务；跨设备同步继续使用可选的 WebDAV。验收包保持运行，Agent 接口仍为本机 `127.0.0.1:17321`。
